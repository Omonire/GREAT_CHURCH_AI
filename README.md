# GREAT_CHURCH_AI

AI-assisted live media operations for churches.

## Vision
GREAT_CHURCH_AI helps church media teams understand live speech, detect Scripture and sermon context, and prepare relevant media in real time while keeping the human media operator in control.

## Product principle
AI recommends. A human operator approves.

## Architecture
Microphone -> realtime transcription -> church intelligence -> media suggestions -> operator approval -> media/broadcast output.

See `docs/architecture.md` and `docs/roadmap.md`.
